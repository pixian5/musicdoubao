## 已完成

- **同步支持 `.m4a` 与 `.qta`**：原脚本只同步 `.m4a`，漏掉 macOS 较新语音备忘录格式 `.qta`（55 条）。已扩展 `is_audio_name`、数据库查询与同名查找，支持两种格式；验证 609 条全部识别，55 条 `.qta` 已同步到 Dropbox。
- **`.qta` 额外转 `.m4a`**：在保留原始 `.qta` 的同时，用 `ffmpeg` 为每条 `.qta` 额外生成一份 `.m4a`（AAC），便于跨平台播放。优先无损复制内部 AAC 流，失败回退重编码。验证 `converted=55, convert_failed=0`。
- **虚拟环境改用 `uv`**：原 `.venv` 因系统 Python 3.14 框架被移除而失效，已用 `uv` 重建（Python 3.14.0），运行命令 `uv run python sync_voice_memos.py`。
- **观测性**：`main()` 的 JSON 输出补充 `converted` / `convert_failed` 字段，便于确认转换情况。

## 运行方式

`uv run python sync_voice_memos.py`（可加 `--watch --interval 30` 持续同步）。
